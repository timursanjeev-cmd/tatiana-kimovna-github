# Татьяна Кимовна — решала всего

Одностраничный шуточный сайт-пародия. Все перечисленные суперуслуги и титулы поданы как комедийные преувеличения, а не как проверенные факты или реальные предложения услуг.

## GitHub Pages

1. Загрузите файлы `index.html`, `README.md` и папку `assets` в корень репозитория.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Все пути к файлам относительные, поэтому сайт корректно работает в GitHub Pages.
